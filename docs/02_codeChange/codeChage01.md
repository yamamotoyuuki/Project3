# 仕様変更
## 概要
 Webアプリの社員一覧は、基本的に管理者画面からは登録しない。
 エージェントアプリをインストールした端末からリクエストされた利用者名を登録するようにしたい。

### 対応
 1. エージェントアプリの変更
  - [x] エージェントアプリを特定するための情報として、「エージェント番号」を保持すること。
  - [x] 起動時に、PC内に保存されたエージェント番号を取得すること。
  - [x] 起動時に、PC内に保存されたエージェント番号が取得できない場合は、データベースから新規エージェント番号を取得すること。（初回起動時を想定）
  - [x] 取得したエージェント番号は、PCに永久に保存すること
 
 2. 管理者アプリの変更
  - [x] PC一覧画面には、「エージェント番号」を現在の項目に加えるて表示すること

 3. バックエンド処理の変更
  - [x] エージェントアプリからのリクエストにある「エージェント番号」が存在しない場合は、登録をすること
  - [x] エージェントアプリからのリクエストにある「エージェント番号」が存在する場合は、更新をすること
  - [x] エージェント番号による新規／更新の処理分岐は、一連の処理の先頭で存在有無を判断し、以降の処理はフラグを使用して判断すること 

 2. データベースの設計変更
  - [x] 「エージェント番号」をプライマリキーとして各種テーブルを紐づけること
  - [x] 「エージェント履歴」テーブルを新設すること（現時点ではテーブルを作るだけです）
