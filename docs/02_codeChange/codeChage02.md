# 仕様変更
## 概要
エージェントアプリの設定タブに「購入／レンタル」区分を追加する。
この対応に伴い、関連する処理（バックエンド）の修正も同時に行う。

### 対応
 1. エージェントアプリの変更
  - [x] エージェントアプリの設定タブから「ホスト名」を削除する
  - [x] エージェントアプリの設定タブに「購入／レンタル」区分を追加する。
  - [x] 追加した「購入／レンタル」は、エージェントアプリ起動時にバックエンドから取得し、取得できない場合にのみ、活性化する。
  - [x] 保存ボタン押下で行われる手動送信において、「購入／レンタル」区分の取得および、項目への値設定を行う。
        但し、手動送信での区分取得は「購入／レンタル」区分をエージェントアプリから設定した場合にのみ行う。すでに設定されている場合は、区分の取得を行わない。
        → 実装: 購入/レンタルいずれかを選択して送信した場合のみ、送信後にバックエンドから再取得して項目に反映する。
               バックエンドから取得済み（disabled）の場合は送信しない・再取得しない。

 2. 管理者アプリの変更
  - [x] この仕様変更に伴う管理者アプリの変更の変更はない想定。この想定が間違いないか確認すること。
        → 確認済み。pc_assets.acquisition_type は既存カラムで管理者画面に表示・編集機能あり。変更不要。
  - 変更が必要な場合は、問い合わせを行い指示を仰ぐこと。

 3. バックエンド処理の変更
  - エージェントアプリの改修に伴い、バックエンドも修正すること。
  - 想定される修正は、以下の通り。不足している場合は、指示を仰ぐこと。また、不足している作業を実施する場合は、以下のリストに追加すること。
  - [x] APIの新規作成（エージェント起動時「購入／レンタル」区分取得: GET /api/v1/agent/asset-info）
  - [x] SecurityConfig に /api/v1/agent/asset-info を permitAll 追加
  - [x] APIのIF変更（手動送信時の「購入／レンタル」区分リクエスト: AgentReportRequest に acquisition_type 追加）
  - [x] 各種API変更に伴い、Java及びSQLの修正（AgentMapper / AgentMapper.xml / AgentService）
