# 不具合
* エージェント画面について
- 送信タブ
 1. 「APIに送信」のラベル名称を「手動送信」に変更すること。
 2. 「手動送信」を押下した際のリクエスト値に、設定タブの「使用者名」も含めること。
- 設定タブ
 1. 設定タブに、使用者名を表示すること
 2. 使用者名は、エージェント画面から入力できること
 3. 設置場所は、ps_assetsテーブルのlocationに登録すること。
 3. 「保存」をクリックすると、「手動送信」を実行すること

* 管理者画面について
- PC一覧画面の一覧を押下して遷移する詳細画面
 1. 「使用者」があるが何も表示されていない。エージェント画面で保存した「使用者名」を表示すること。
 2. 「設定場所」があるが何も表示されていない。エージェント画面で保存した「設置場所」を表示すること。
