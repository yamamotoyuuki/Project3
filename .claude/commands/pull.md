# プル

リモートリポジトリから最新のソースをプルしてください。

---

## 実行手順

### ステップ1: 現在の状態を確認する

```
git status
```

未コミットの変更がある場合は、その内容をユーザーに提示し、プルを続けるか確認する。

---

### ステップ2: プルを実行する

```
git pull
```

---

### ステップ3: 完了を報告する

以下の情報を含む完了メッセージを表示する:
- 取得したコミット数
- 更新されたファイル一覧
- 現在のブランチ名
- 最新コミットのハッシュとメッセージ

エラーが発生した場合（コンフリクトなど）は内容を報告し、対処方法を提示する。
